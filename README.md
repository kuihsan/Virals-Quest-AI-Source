# 🎮 Virals Quest

**Virals Quest** is an improvement of 3D dyscalculia identification game by **Ku Muhammad Ihsanuddin Bin Ku Ishak (Ku Ihsan)**.  
The project focuses on dynamic **NPC interaction**, **decision-based gameplay**, and **AI-powered dialogue systems** — designed to create meaningful player experiences where *every conversation matters*.

---

## 🧩 Overview

In *Virals Quest*, players explore a world recovering from a viral outbreak, meeting various survivors, traders, and rogue AI entities.  
Each NPC reacts differently based on the player’s choices, fostering replayability and emotional depth.

The project was built as part of my **final year project (PSM)** at **Universiti Teknikal Malaysia Melaka (UTeM)**, combining storytelling, artificial intelligence, and game programming into a cohesive gameplay experience.
