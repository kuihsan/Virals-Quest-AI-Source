# 🎮 Virals Quest

**Virals Quest** is an AI-driven 2D adventure game developed by **Ku Muhammad Ihsanuddin Bin Ku Ishak (Ku Ihsan)**.  
The game focuses on dynamic **NPC interaction**, **decision-based gameplay**, and **AI-powered dialogue systems** — designed to create meaningful player experiences where *every conversation matters*.

---

## 🧩 Overview

In *Virals Quest*, players explore a world recovering from a viral outbreak, meeting various survivors, traders, and rogue AI entities.  
Each NPC reacts differently based on the player’s choices, fostering replayability and emotional depth.

The project was built as part of my **final year project (PSM2)** at **Universiti Teknikal Malaysia Melaka (UTeM)**, combining storytelling, artificial intelligence, and game programming into a cohesive gameplay experience.

---

## ⚙️ Features

- 🧠 **AI-Powered NPC System** — Dynamic responses and behaviors generated from predefined emotional states.  
- 💬 **Dialogue Decision Trees** — Player choices influence story outcomes and NPC attitudes.  
- 🎭 **Emotional State Engine** — NPCs change tone and response patterns based on in-game events.  
- 🎨 **2D Adventure Environment** — Built with Unity’s Tilemap and sprite-based art style.  
- 🎧 **Immersive Sound Design** — Ambient audio and adaptive soundtracks react to player progress.  
- 🧾 **Data-Driven Design** — Uses JSON-based dialogue and state storage for flexible updates.

## 🧠 Core Concept

> “Every NPC is more than a quest-giver — they remember, react, and evolve.”

The heart of *Virals Quest* lies in **simulated empathy**. NPCs track player actions (help, harm, trade, etc.) and adjust behavior dynamically. This mechanic encourages players to think morally and strategically rather than simply completing tasks.
